Enterprise OpenHRMS Official Announcements
==========================================

This module helps you to manage hr official announcements.

Key Features
------------
* **Targeted & General Announcements:** Broadcast company-wide notices or target specific employees, departments, or job positions.
* **Approval Workflow:** Manage announcement status with Draft, Waiting for Approval, Approved, and Rejected stages.
* **Employee Profile Smart Button:** View and track all applicable announcements directly from the employee form view.
* **Automated Expiry Tracking:** Set validity date ranges and automatically manage expired announcements with scheduled actions.
* **Attachment Support:** Attach official circulars, policy documents, and files directly to announcement records.
* **Role-Based Access Control:** Secure permissions tailored for Employees, HR Officers, and HR Managers.


Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
