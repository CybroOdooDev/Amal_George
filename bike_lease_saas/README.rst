Bike Lease Management for Odoo Online
=========================================
A comprehensive Bike Lease Management SaaS application developed for Odoo Online 19.4 (saas19.4). It streamlines bike leasing operations by managing customizable lease plans, customer applications, automated contracts, itemized installment schedules with daily vehicle surcharges, return inspections, security deposit net settlements, bike fleet vehicle inventory, maintenance service logs, and real-time operational analytics dashboard.

Key Features
============
* **Interactive Analytics Dashboard**: Real-time KPI summary, multi-year horizontally scrollable revenue trend chart, fleet status distribution, model yield polar chart, reliability matrix, and overdue watchlist tables.
* **Flexible Lease Plans**: Configure Daily, Weekly, Monthly, Quarterly, and Yearly lease plans with base fees, required security deposits, and late fee configurations.
* **Lease Application Pipeline**: Full stage workflow (`Draft` -> `Submitted` -> `Under Review` -> `Approved` / `Rejected`) with automated bike availability checks, assigned vehicle allocation, and rejection reasons tracking.
* **Contract & Installment Engine**: Automated lease contract creation, security deposit invoice automation, itemized installment schedules calculating base lease fees and additional daily vehicle surcharges, payment sync, and overdue tracking.
* **Vehicle Return Inspection & Settlement**: Interactive return wizard logging inspection issues, repair charges, and generating automated net deposit settlement invoices (Deposit Refund or Extra Collection Charge).
* **Native Fleet & Invoicing Integration**: Integrated with standard Odoo Fleet Management and Odoo Customer Invoicing with automatic vehicle status updates (`Available`, `Leased`, `Maintenance`, `Retired`).
