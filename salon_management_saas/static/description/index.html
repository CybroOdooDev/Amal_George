Frequently Asked Questions

How does the booking and invoicing process work?
Clients can book online via /salon-booking or staff can create manual bookings in the backend. Once confirmed, resources (chairs) and beauticians are locked. When the appointment is completed, staff can generate the customer invoice directly from the booking screen.
How does the double booking prevention system work?
When creating or confirming bookings, Odoo runs automated check rules. If the chosen beautician or chair is already booked for an overlapping time slot, or if the time falls during lunch breaks or holidays, the system throws a UserError.
Can I bundle multiple treatments together?
Yes, the Service Package feature allows you to group multiple services, set a package-wide discount rate, configure validity dates, and select authorized staff.
