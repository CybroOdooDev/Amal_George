Frequently Asked Questions

What is Mobile Service Management Pro?

It is an advanced extension of the Mobile Service Management module that adds checkimei.com lookup integrations, real device picture captures, analytical graphs/pivots, and three new report wizards with Excel exporting capability.

Do we need an API key for checkimei.com lookup?

Yes, you need to register on checkimei.com to get an API key. They provide limited free credits for testing purposes, and you can top up your account balance for high-volume production searches.

How does the device image lookup API work?

When a service request is created and a device model is identified, the system connects to the MobileAPI.dev API to automatically fetch and attach a high-quality catalog image of that phone model to the Odoo record.

Which custom reports can be printed/exported?

There are 3 custom reports included: Service Reports, Parts Usage Reports, and Complaint Type Reports. Technicians can use Odoo action wizards to filter reports by date, state, customer, etc. and print them as PDFs or download XLSX files.
