Navigate to Payment Providers

In your Odoo Website app, navigate to Configuration > Payments to view and configure payment gateways.

Locate Saferpay in Payment Providers

Find the Saferpay payment gateway in the payment providers list, ready for configuration and publishing.

Saferpay Configuration Form View

Open the Saferpay provider form and select the Configuration tab to locate the credentials fields: Customer ID, Terminal ID, Username, and Password.

Saferpay Backoffice Terminal Settings

Log into your Worldline Saferpay Backoffice account and navigate to Settings > Payment Means & Terminals.

Retrieve Customer ID & Terminal ID

Locate your Customer ID and Terminal ID in the Saferpay Backoffice header and terminal selector.

JSON API Basic Authentication Setup

Under Settings in Saferpay Backoffice, select JSON API Basic Authentication and click the Create button to set up an API user.

Create JSON API Login Credentials

Enter a secure API password and description (e.g. Payment_Gateway), then click Create to generate the credentials.

Copy Generated API Username & Password

Copy the auto-generated JSON API Username and save your password securely to configure in Odoo.

Configure & Publish in Odoo Backend

Paste Customer ID, Terminal ID, Username, and Password into Odoo, select your bank payment journal, and publish the provider.

eCommerce Cart & Checkout Review

Customer adds items to cart in the Odoo eCommerce shop, reviews order summary and taxes, and proceeds to Checkout.

Select Saferpay on Payment Step

On the checkout payment screen, customer selects Saferpay as the payment method and clicks the "Pay now" button.

Secure Saferpay Hosted Payment Page

Customer is securely redirected to Worldline Saferpay's hosted interface to enter card details (Visa, Mastercard, Amex, etc.) with 3D-Secure.

Automatic Order & Payment Confirmation

Once authorized, the customer is seamlessly returned to Odoo with an immediate order confirmation and success notice.

Real-Time Provider Transaction Counter

In Odoo backend, the Saferpay provider smart button tracks total transaction volume and count in real time.

Confirmed Payment Transaction Record

Review the detailed payment transaction record in Confirmed and Post-processed state, linked with the sales order and provider reference.

Answers Before You Install

Q
Does this module support both Odoo 20 Community and Enterprise Editions?
A
Yes, it is fully certified for Odoo 20 Community Edition and also operates seamlessly on Odoo 20 Enterprise and Odoo.sh. No proprietary Enterprise license is required to configure and run the Saferpay payment gateway.
 
Q
What Saferpay Backoffice credentials are required?
A
You need four credentials obtained from your Saferpay Backoffice account: Customer ID, Terminal ID, JSON API Username, and JSON API Password. API credentials can be generated under Settings > JSON API basic authentication in Saferpay Backoffice.
 
Q
Is sensitive cardholder data stored on the Odoo server?
A
No. The integration utilizes Saferpay's Level 1 PCI-DSS compliant Hosted Payment Page. Credit card details, CVVs, and 3-D Secure authentication are processed exclusively on Worldline Saferpay's secure servers, ensuring complete compliance and zero cardholder data footprint in Odoo.
